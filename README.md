# House Price Prediction using Machine Learning

## Overview

This project predicts house prices using Machine Learning techniques on the Ames Housing Dataset. The workflow includes Exploratory Data Analysis (EDA), Feature Engineering, Feature Selection, and Model Training to identify the most important factors affecting house prices.

## Dataset

* Ames Housing Dataset
* 79 explanatory features
* Target Variable: SalePrice

## Project Workflow

### Exploratory Data Analysis (EDA)

* Data understanding and visualization
* Missing value analysis
* Feature distribution analysis

### Feature Engineering

* Missing value handling
* Feature transformation
* Data preprocessing

### Feature Selection

* Applied Lasso Regression for feature selection
* Reduced features from 82 to 21 important predictors

### Model Development

* Data scaling and preprocessing
* Regression model training
* Performance evaluation
